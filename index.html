Minecraft Java & Bedrock

Look up a player to see their profile

Profile, skin and UUID come from public APIs. Detailed stats need the player's stats file or a server stats API — see the Data guide.

Enter a server address

Shows status, version, player count and MOTD when the server exposes them. Bedrock defaults to port 19132, Java to 25565.

What this site can and can't show

Minecraft does not publish per-player statistics by username. This site only shows data it can actually get, and labels where each value came from.

Works right away

  • Java profile: username, UUID, skin, cape, name history (PlayerDB and Ashcon).
  • Bedrock profile: XUID, Floodgate UUID and skin when the player has a skin on the GeyserMC Global API.
  • Server checker: Java and Bedrock status via mcstatus.io, with mcsrvstat.us as backup.

Needs your files or a server

  • Java statistics and advancements live in world/stats/<uuid>.json and world/advancements/<uuid>.json. Import them on the Player or Boards tab, or point Settings at a stats API you run.
  • World age and hardcore flag come from level.dat (import it too).
  • Bedrock statistics have no vanilla file or public API. Only a plugin or add-on on a server you control could provide them.
  • Leaderboards rank only the players you imported on this device. There is no worldwide ranking and no verified global survival record, so none are shown.

Why "not recorded" is not zero

Minecraft leaves out any stat that is still zero, so a missing entry could mean zero or a version that does not track it. The site shows a dash instead of guessing.

Privacy

Everything runs in your browser. Imported files stay on this device (localStorage) and are never uploaded. Lookups send the name you typed to the public APIs listed in Settings.

Settings

API addresses are editable so you can swap a service if it goes down. No keys or secrets belong here.

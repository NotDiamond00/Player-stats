How data works

Transparent sources, no made-up stats.

What works with a username?

For Java Edition, the page attempts to resolve a public profile through Mojang's public profile endpoint and display its UUID and skin. Bedrock gamertag resolution varies and is not universally available without a compatible provider.

Why are detailed stats unavailable?

Vanilla detailed statistics and advancement progress are generally stored in a player's world/server data. They are not exposed by the public Java profile service. A server plugin/API or an authorized export of world/player data is needed.

Can I publish this on GitHub Pages?

Yes. This is a static HTML file with embedded CSS and JavaScript. It can be published from a repository root using Settings → Pages. Public API availability and browser CORS policies may affect individual lookups.

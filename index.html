How data works

What works with a username?

Java profile lookup can provide a public UUID and skin when the service is available. Bedrock gamertag lookup varies by provider.

Why are detailed stats unavailable?

Block counts, advancement progress, movement, playtime and survival duration generally require world/player data or a server API/plugin that exposes them.

Can I publish on GitHub Pages?

Yes. This is one static HTML file with embedded CSS and JavaScript. GitHub Pages does not run Python backend code.
